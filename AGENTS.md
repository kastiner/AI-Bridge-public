# Agent instructions

This is a public, sanitized repository.

## Read order

1. `README.md`
2. `PRIVACY.md`
3. `docs/WORKFLOW.md`
4. Relevant template under `docs/templates/`
5. Relevant rule under `skills/`

## Safety boundary

- Never import content from a private repository unless the user supplies and approves a sanitized version.
- Never add personal data, photographs, financial records, credentials, private infrastructure, or unpublished research.
- Treat examples in this repository as synthetic unless explicitly cited otherwise.
- Show the complete draft before creating a public issue or comment.
- Do not present an LLM synthesis as a participant's own view.

## Writing style

- Concise and factual
- Explicit about whose perspective is represented
- Clear separation between observation, interpretation, and proposed action
- No claims of consensus until participants confirm it
