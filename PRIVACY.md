# Privacy and publication boundary

This repository is public. Assume that every committed file can be copied, indexed, and retained permanently.

## Allowed

- Generic workflows and templates
- Synthetic examples
- Publicly documented software setup instructions
- De-identified lessons that do not reveal a person, institution, project, or unpublished result

## Prohibited

- Names, account identifiers, email addresses, photographs, signatures, or attendance records
- Receipts, expenditure records, bank information, or administrative forms
- Credentials, tokens, private repository URLs, server names, network details, or access instructions
- Patient or specimen identifiers
- Unpublished figures, manuscripts, experimental results, or collaborator correspondence
- Candid internal assessments that were created for a private project context

## Before publishing a change

1. Confirm that the content is intended for public distribution.
2. Remove identifying metadata from documents and images.
3. Replace real examples with synthetic ones.
4. Check links: do not link to private files or systems.
5. Search the staged diff for names, emails, credentials, internal paths, and research identifiers.
6. Obtain human approval before posting an AI-generated issue, comment, or document.

Making a repository private later does not retract copies made while it was public.
