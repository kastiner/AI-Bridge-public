# Contributing

Contributions should improve the reusable public toolkit without importing private project evidence.

## Contribution rules

- Use synthetic examples unless the source is already public and appropriately cited.
- Keep computational and experimental perspectives distinct until the disagreement is explicitly resolved.
- Label LLM-generated drafts and require human review before publication.
- Do not add names, photographs, receipts, unpublished science, private links, or infrastructure details.
- Keep one issue or pull request focused on one purpose.

Before submitting, read [`PRIVACY.md`](PRIVACY.md) and review the complete staged diff.
