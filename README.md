# AI-Bridge Public Toolkit

AI-Bridge is a lightweight toolkit for structured communication between computational and experimental researchers, with optional large language model (LLM) assistance.

This public repository contains reusable workflow documents, discussion templates, and agent-writing rules. It is a **sanitized distribution repository**: it does not contain participant records, meeting photographs, financial evidence, unpublished research material, or the private project archive.

## What this repository is for

- Preparing interdisciplinary research meetings
- Recording where computational and experimental interpretations differ
- Running structured two-round GitHub issue discussions
- Using an LLM to translate terminology, organize questions, and draft clearly labeled summaries
- Testing whether a GitHub-connected assistant can read a public repository safely

## What this repository is not for

- Uploading identifiable participant information
- Storing patient, animal, or unpublished experimental data
- Publishing private meeting records or administrative evidence
- Treating LLM-generated text as a participant's confirmed position
- Allowing an assistant to post publicly without human review

## Start here

1. Read [`PRIVACY.md`](PRIVACY.md).
2. Read [`docs/WORKFLOW.md`](docs/WORKFLOW.md).
3. Choose a template under [`docs/templates/`](docs/templates/).
4. If using an AI coding or collaboration agent, read [`AGENTS.md`](AGENTS.md) and the files under [`skills/`](skills/).
5. For public-repository connection testing, use [`docs/CONNECTING_GITHUB.md`](docs/CONNECTING_GITHUB.md).

## Status

This repository is prepared as a public toolkit and connection-test surface. The underlying project found that GitHub can work well as an archive, but successful interdisciplinary communication still depends on human discussion, explicit interpretation boundaries, and deliberate review of AI-assisted drafts.
